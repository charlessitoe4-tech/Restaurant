# Restaurante — Sabores da Casa

Site responsivo para consultar o menu, montar pedidos para consumo no restaurante ou entrega, solicitar reservas e aceder aos painéis da equipa.

## Executar

Abra `index.html` num navegador ou sirva a pasta com um servidor HTTP local. Os pedidos, as reservas, o menu e as contas de demonstração são guardados no armazenamento local do navegador.

## Acessos de demonstração

Na secção **Acesso da equipa**, abra **Ver acessos de demonstração**:

| Perfil | Utilizador | Palavra-passe |
| --- | --- | --- |
| Admin | `admin` | `Adm!nRest2025` |
| Caixa | `caixa` | `C@ixa2025` |
| Garçom | `garcom` | `G@rcom2025` |
| Delivery | `delivery` | `D3liVery#2025` |

Estas contas são apenas para demonstração local. A autenticação atual do site é executada no navegador e não deve ser usada para proteger dados ou operações em produção. Para utilização real, ligue os formulários ao serviço de autenticação do backend e substitua as credenciais de demonstração.
